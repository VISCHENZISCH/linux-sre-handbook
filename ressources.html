Ressources d'apprentissage

Documentation officielle, tutoriels, vidéos, outils et labs, classés par thème.

36 ressources Tous niveaux Mis à jour Novembre 2026
Les ressources ci-dessous sont organisées dans l'ordre d'utilisation recommandé. Le stagiaire est encouragé à consulter la documentation officielle en priorité et à utiliser les tutoriels vidéo pour comprendre les concepts globaux.
Doc officielle Tutoriel Vidéo Guide Outil Lab Référence

Linux et administration système

Les bases indispensables avant d'aborder la conteneurisation : shell, système de fichiers, permissions, processus et services.

  1. Linux Journey Parcours progressif et gratuit : ligne de commande, permissions, processus, réseau. Tutoriellinuxjourney.com
  2. The Linux Command Line (William Shotts) Livre gratuit de référence pour maîtriser le shell Bash. Guidelinuxcommand.org
  3. ArchWiki Documentation communautaire très détaillée, utile quelle que soit la distribution. Référencewiki.archlinux.org
  4. Documentation du noyau Linux Référence officielle du kernel : sysctl, cgroups, ordonnanceur, mémoire. Doc officiellekernel.org
  5. Linux Performance (Brendan Gregg) Outils et méthodologies d'analyse de performance Linux. Référencebrendangregg.com

Docker et conteneurisation

Comprendre les images, les conteneurs, les volumes et les réseaux, puis écrire des Dockerfile sûrs et légers.

  1. Docker - Get Started Documentation officielle : concepts, premier conteneur, Compose. Doc officielledocs.docker.com
  2. Docker Curriculum Tutoriel complet et gratuit, de l'installation au déploiement. Tutorieldocker-curriculum.com
  3. TechWorld with Nana - Docker Tutorial for Beginners Vue d'ensemble des concepts Docker en vidéo (YouTube). Vidéoyoutube.com
  4. Bonnes pratiques de sécurité Dockerfile Image minimale, utilisateur non-root, multi-stage, gestion des secrets. Guidesysdig.com
  5. Hadolint Linter Dockerfile : détecte les mauvaises pratiques avant le build. Outilgithub.com
  6. Trivy Scanner de vulnérabilités pour images, fichiers IaC et dépôts. Outiltrivy.dev

Kubernetes

Déployer, exposer et superviser des applications conteneurisées, puis vérifier la qualité et la sécurité des manifests.

  1. Tutoriels officiels Kubernetes Parcours pas à pas : déploiement, Services, configuration, stateful. Doc officiellekubernetes.io
  2. kubectl Quick Reference Aide-mémoire officiel des commandes kubectl. Référencekubernetes.io
  3. TechWorld with Nana - Kubernetes Tutorial for Beginners Architecture et objets Kubernetes expliqués en vidéo (YouTube). Vidéoyoutube.com
  4. kube-score Analyse statique des manifests et recommandations de fiabilité. Outilkube-score.com
  5. kubesec Score de sécurité des ressources Kubernetes. Outilkubesec.io
  6. Checkov Scan de l'Infrastructure as Code : Kubernetes, Terraform, Helm. Outilcheckov.io

CI/CD et GitHub Actions

Automatiser le build, les tests et le déploiement à chaque commit.

  1. GitHub Skills - GitHub Actions Labs interactifs officiels, réalisés directement dans un dépôt. Lablearn.github.com
  2. Documentation GitHub Actions Workflows, runners, secrets, environnements et réutilisation. Doc officielledocs.github.com
  3. TechWorld with Nana - GitHub Actions Tutorial Concepts de base et pipeline CI/CD avec Docker (YouTube). Vidéoyoutube.com

DevSecOps - Vision globale

Intégrer la sécurité à chaque étape du cycle de vie, du code à la production.

  1. OWASP DevSecOps Guideline Référentiel OWASP pour construire un pipeline DevSecOps. Guidegithub.com
  2. TechWorld with Nana - Complete DevSecOps Bootcamp Panorama complet des pratiques DevSecOps (YouTube). Vidéoyoutube.com

Outils de scan

Analyse statique du code, détection de secrets et audit des dépendances, à brancher dans la CI.

  1. Semgrep SAST multi-langage, avec un playground en ligne pour tester ses règles. Outilsemgrep.dev
  2. Gitleaks Détection de secrets (clés, tokens) dans le code et l'historique Git. Outilgithub.com
  3. OWASP Dependency-Check Identification des dépendances présentant des CVE connues. Outilowasp.org
  4. Bandit SAST dédié au code Python. Outilbandit.readthedocs.io

Labs pratiques

La pratique sur de vrais incidents est le meilleur moyen de consolider les acquis.

  1. SadServers Scénarios de dépannage Linux sur de vrais serveurs cassés, à réparer en temps limité. Labsadservers.com
  2. OverTheWire - Bandit Wargame progressif pour maîtriser la ligne de commande et les bases de la sécurité. Laboverthewire.org
  3. Killercoda Environnements Linux et Kubernetes interactifs dans le navigateur. Labkillercoda.com
  4. roadmap.sh - DevOps Feuille de route visuelle des compétences DevOps. Guideroadmap.sh

SRE et observabilité

Mesurer la fiabilité (SLI, SLO, budgets d'erreur) et instrumenter les systèmes.

  1. Livres SRE de Google Site Reliability Engineering, The Site Reliability Workbook, gratuits en ligne. Guidesre.google
  2. Prometheus - Overview Modèle de données, PromQL et alerting. Doc officielleprometheus.io
  3. Documentation Grafana Tableaux de bord, sources de données et alertes. Doc officiellegrafana.com

SOC et sécurité défensive

Premières ressources pour la future section SOC : détection, réponse à incident et supervision de sécurité.

  1. MITRE ATT&CK Base de connaissances des tactiques et techniques des attaquants. Référenceattack.mitre.org
  2. Sigma Format générique de règles de détection, convertible vers les principaux SIEM. Outilgithub.com
  3. Documentation Wazuh SIEM / XDR open source : agents, règles, conformité. Doc officielledocumentation.wazuh.com
